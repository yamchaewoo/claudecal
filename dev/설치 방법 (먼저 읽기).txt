ClaudeCal 설치 방법 (Windows 10·11)
====================================

대충 적으면 구글 캘린더 일정이 되는 위젯이에요. 처음 한 번만 아래 순서대로 해 주세요.


1. 파이썬 설치 (이미 있으면 건너뛰기)
   - https://www.python.org/downloads/ 에서 [Download Python] 받아 실행
   - 설치 첫 화면 맨 아래 "Add python.exe to PATH" 를 꼭 체크하고 [Install Now]

2. 위젯 설치
   - 이 압축을 아무 데나 풀어요 (예: 문서 폴더). 바탕화면·다운로드 폴더 말고 오래 둘 곳으로요.
   - 폴더 안의 install.bat 을 더블클릭
     → 필요한 부품 설치, 윈도우 켤 때 자동 실행 등록, 위젯 실행까지 알아서 해요 (1~2분).
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]

3. Claude API 키 넣기 (각자 본인 것)
   - https://console.anthropic.com 가입·로그인 → API Keys → Create Key → 키 복사
   - 위젯 ⋯ → 설정 → Anthropic API 키에 붙여넣고 [저장]
   - 사용료는 본인 계정에서 나가요. Sonnet 기준 한 번에 10원 남짓, ⚡ 표시가 뜨는 단순한 등록은 0원.
   - 키가 없어도 "내일 3시 치과" 같은 단순한 등록(⚡)은 돼요.

4. 구글 캘린더 연결
   - 위젯 ⋯ → 설정 → [구글 캘린더 연결] → 본인 구글 계정으로 로그인
   - "Google에서 확인하지 않은 앱" 이 나오면 [고급] → [ClaudeCal(으)로 이동]
   - 캘린더·할 일 권한에 체크하고 [계속]

5. 휴대폰 앱 (원하면)
   - 휴대폰에서 https://yamchaewoo.github.io/claudecal/app/ 열기
   - 카톡으로 받은 링크를 누르면 카톡 안의 브라우저로 열려서 홈 화면 추가·구글 로그인이 안 돼요.
     → 오른쪽 아래 ⋮ → "다른 브라우저로 열기" (안드로이드는 Chrome, 아이폰은 Safari)
   - 안드로이드: Chrome ⋮ → 홈 화면에 추가 / 아이폰: Safari 공유 → 홈 화면에 추가
   - 홈 화면 아이콘으로 열어서 같은 구글 계정으로 로그인하고 API 키 넣기


쓰는 법
-------
- 오른쪽 아래 ✱ 버튼을 누르거나 Ctrl+Shift+Space → "내일 3시 치과" 처럼 적고 Enter
- 목록·주·월 보기, 왼쪽 칸은 날짜 없는 할 일, 일정 옆 체크칸은 완료 표시
- 끌어서 옮기기: 일정을 다른 날짜로 끌면 그날로 (시간 그대로), 할 일을 날짜로 끌면 일정으로,
  일정을 왼쪽 할 일 칸으로 끌면 날짜 없는 할 일로. 잘못 옮겼으면 Ctrl+Z
  (휴대폰 앱은 일정·할 일을 꾹 누르면 아래에 날짜 띠가 떠요. 거기로 끌어 놓거나 손을 떼고 날짜를 누르면 돼요)
- 끄기: ⋯ → 끄기 / 다시 켜기: 이 폴더의 claude_cal.pyw 더블클릭
- 업데이트는 알아서 돼요. 새 버전이 나오면 위젯이 받아 두었다가 창을 접어 둘 때 조용히 다시 켜져요.
  다시 다운받을 필요 없어요. (⋯ → 설정 → 업데이트에서 끄거나 바로 확인할 수 있어요)
