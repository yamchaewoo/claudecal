화면 오른쪽 아래에 있는 작은 버튼을 누르고 한 줄로 적은 뒤 Enter를 누르면, 날짜와 시간을 알아서 읽어 구글 캘린더에 일정을 넣어 줘요. 일정 보기, 수정, 삭제, 반복 일정, 일정 전 알림도 이 위젯 하나로 할 수 있어요.

구글 캘린더를 쓰는 이유

ClaudeCal은 사용자가 직접 연결을 허락했을 때만 구글 캘린더에 접근해요. 허락받는 권한은 calendar.events 하나이고, 다음 일에만 써요.

  • 위젯 화면(목록·주·월)에 내 일정 보여 주기
  • 내가 입력하거나 고친 대로 일정 등록·수정·삭제하기
  • 일정 시작 전에 Windows 알림 보내기

ClaudeCal은 각자 PC에서 실행되는 프로그램이고, 따로 운영하는 서버가 없어요. 그래서 내 캘린더 정보가 개발자에게 전달되지 않아요. 자세한 내용은 개인정보처리방침을 봐 주세요.

누가 쓰나요

개인이 만든 무료 프로그램이에요. 만든 사람과 친구들이 각자 PC에 설치해서 써요. 광고나 결제는 없어요.

ClaudeCal is a small, free Windows desktop widget that turns short notes typed in Korean into Google Calendar events. It runs only on the user's own PC, requests the calendar.events scope only after the user agrees, and never sends calendar data to the developer. See the Privacy Policy.
