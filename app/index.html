ClaudeCal 시작하기

대충 적으면 Claude가 읽어서 구글 캘린더에 넣어 줘요. 처음 한 번만 두 가지를 해 주세요.

1
구글 캘린더 연결
"확인되지 않은 앱" 화면이 나오면 고급 → ClaudeCal(으)로 이동을 누르고, 캘린더 권한에 체크해 주세요.
2
Claude API 키
console.anthropic.com → API Keys에서 만들 수 있어요. 키는 이 휴대폰에만 저장돼요.
+
홈 화면에 추가
추가하면 앱처럼 열리고, 안드로이드에선 카톡 메시지 공유 → ClaudeCal로 바로 등록돼요. 아이폰은 Safari 공유 → 홈 화면에 추가.
