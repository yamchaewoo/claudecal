개인정보처리방침

ClaudeCal · 시행일 2026년 10월 29일

한 줄 요약: ClaudeCal은 내 PC와 내 휴대폰에서만 돌아가요. 구글 캘린더 일정은 일정 관리에만 쓰고, 개발자에게 보내거나 팔지 않아요. 문장 해석을 위해 내가 넣은 본인의 Claude API 키로 Anthropic에 필요한 만큼만 보내요.

1. ClaudeCal은 어떻게 동작하나요

ClaudeCal은 각자 Windows PC에 설치해서 쓰는 위젯이에요. 개발자가 운영하는 서버나 계정 시스템이 없어서, 사용자의 정보가 개발자에게 전달되지 않아요.

휴대폰 앱도 같은 방식이에요. 이 사이트에서 받은 화면이 휴대폰 브라우저 안에서 돌아가면서 구글과 Anthropic에 직접 연결해요. 이 사이트(GitHub Pages)는 화면 파일만 내려 줄 뿐, 입력한 글이나 일정을 받지 않아요. 안드로이드에서 다른 앱의 글을 공유 → ClaudeCal로 보내면, 그 글은 직접 입력한 문장과 똑같이 처리돼요.

2. 접근하는 구글 사용자 데이터

사용자가 위젯 설정에서 구글 캘린더 연결을 누르고 구글 화면에서 허락했을 때만 접근해요.

  • 권한: https://www.googleapis.com/auth/calendar.events (캘린더 일정 보기·만들기·수정·삭제)
  • 읽는 정보: 기본 캘린더 일정의 제목, 날짜·시간, 장소, 메모, 반복 규칙, 알림 설정
  • 계정 이메일: 설정 화면에 "어느 계정에 연결됐는지" 보여 주는 데에만 써요 (기본 캘린더 이름에서 읽어요)

3. 데이터를 쓰는 곳

  • 위젯 화면(목록·주·월)에 일정 보여 주기
  • 사용자가 입력하거나 고친 대로 일정 등록·수정·삭제하기, 되돌리기
  • 완료 체크: 그 일정의 숨은 칸(앱 전용 속성)에 '완료' 표시만 남겨서, PC와 휴대폰에서 똑같이 보이게 하기
  • 일정 시작 전 Windows 알림 보내기
  • 사용자가 원할 때 이 PC에 저장해 둔 일정을 구글 캘린더로 옮기기

광고, 판매, 분석, 신용 평가 등 다른 목적으로는 쓰지 않아요.

4. 저장하는 곳

모든 정보는 사용자 PC의 %APPDATA%\ClaudeCal 폴더에만 저장돼요.

  • 구글 로그인 토큰(구글 캘린더에 접근하기 위한 열쇠)과 연결된 계정 이메일
  • 설정 (단축키, 알림 시간, 사용자가 넣은 Claude API 키 등)
  • 구글을 연결하지 않았을 때의 일정, 그리고 구글로 옮길 때 남기는 백업 파일

구글 캘린더 일정 자체는 구글 캘린더에 저장돼요. 위젯은 화면과 알림을 위해 켜져 있는 동안만 메모리에 들고 있어요. 최근 입력과 되돌리기 기록도 메모리에만 있고, 위젯을 끄면 사라져요.

휴대폰 앱은 그 휴대폰 브라우저의 저장소(이 사이트 전용)에만 저장해요.

  • 구글 접근 토큰(1시간 동안만 쓸 수 있는 열쇠)과 연결된 계정 이메일
  • 사용자가 넣은 Claude API 키, 고른 모델
  • 보내기 전의 입력 중인 글, 공유받아 잠깐 맡아 둔 글

5. 다른 곳으로 보내는 정보

"모레 저녁 7시 동기 모임" 같은 문장을 해석하기 위해, 사용자가 직접 넣은 본인의 Anthropic API 키(또는 본인의 Claude Code 로그인)로 Anthropic의 Claude에 다음 내용을 보내요.

  • 사용자가 입력한 문장
  • 가까운 날짜 일정의 제목, 날짜·시간, 장소, 반복 여부 ("시험 미뤄줘"처럼 기존 일정을 고칠 때 어떤 일정인지 찾기 위해서예요. 메모는 보내지 않아요.)

PC 위젯은 날짜·시간·제목만 있는 단순한 입력을 Claude에 보내지 않고 PC에서 바로 처리해요. 휴대폰 앱은 휴대폰에서 바로 Anthropic으로 보내요. Anthropic이 받은 정보를 다루는 방식은 Anthropic 개인정보처리방침을 따라요. 이 밖에는 어떤 제3자에게도 구글 사용자 데이터를 보내거나 팔지 않아요.

6. Google API 서비스 사용자 데이터 정책 준수

ClaudeCal이 Google API에서 받은 정보를 쓰고 다른 앱으로 보내는 방식은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요구 사항을 포함해 그 정책을 따라요. 구글 사용자 데이터를 AI 모델 학습에 쓰지 않고, 사람이 읽지도 않아요.

7. 연결 해제와 삭제

  • 위젯 ⋯ → 설정 → 구글 캘린더 → 연결 해제를 누르면 PC에 저장된 구글 로그인 토큰이 지워져요.
  • 구글 계정 → 서드 파티 연결에서 ClaudeCal의 접근 권한을 언제든 없앨 수 있어요.
  • %APPDATA%\ClaudeCal 폴더를 지우면 PC에 남은 모든 정보가 지워져요.
  • 휴대폰 앱은 ⚙ 설정 → 연결 끊기로 구글 토큰과 이메일이 지워지고, 브라우저 설정에서 이 사이트의 데이터를 지우면 API 키까지 모두 지워져요.

8. 어린이

ClaudeCal은 만 14세 미만 어린이를 위한 서비스가 아니에요.

9. 바뀔 때

이 방침이 바뀌면 이 페이지에 새 내용과 시행일을 올려요.

English summary

ClaudeCal is a desktop widget that runs only on the user's own Windows PC, plus a mobile web app that runs entirely in the user's phone browser and talks directly to Google and Anthropic (this site only serves the static app files); the developer operates no server and receives no user data. The mobile app keeps the short-lived Google access token, the account email, the user's API key and unsent input only in that browser's site storage. A "done" mark is stored as an app-private extended property on the event. With the user's consent it uses the Google Calendar scope calendar.events solely to display, create, edit and delete the user's events and to show reminders. The OAuth token, the connected account's email address and settings are stored locally in %APPDATA%\ClaudeCal. To interpret free-text input, the typed sentence and the title, time, location and recurrence flag of nearby events are sent to Anthropic's Claude using the user's own API key; event notes are never sent. Google user data is not sold, used for advertising, used to train AI models, or shared with anyone else. ClaudeCal's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Users can revoke access at any time from their Google Account or with "Disconnect" in the widget, and delete all local data by removing the folder above.
