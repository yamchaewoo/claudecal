# ClaudeCal — 대충 적으면 일정이 되는 위젯 (Windows)

화면 구석에 항상 떠 있는 입력창에 적고 Enter만 누르면 됩니다.

| 이렇게 적으면 | 이렇게 돼요 |
| --- | --- |
| `11/20 금 3시 조합론 시험` | ⚡ 11/20(금) 15:00~16:00 바로 등록 (Claude 안 거침, 0.1초) |
| `다음주 화 PAE 에세이 마감` | ⚡ 해당 날짜 종일 일정 |
| `모레 저녁 7시 강남에서 동기 모임` | 시간 + 장소까지 등록 (Claude) |
| `매주 화목 3시 수업 12월까지` | 반복 일정 등록 |
| `시험 30분 전에 알려줘` | 그 일정 알림을 30분 전으로 |
| `11월 20일에 뭐 있어?` / `이번주 일정` | 그 기간 일정 목록 |
| `시험 4시반으로 미뤄줘` / `이번주 수업만 취소` | 수정 / 삭제 (지우기 전엔 한 번 물어봐요) |

- **⚡ 빠른 등록**: 날짜·시간·제목만 있는 단순한 입력은 Claude 없이 바로 처리해요. 조금이라도 애매하면 Claude에게 넘겨요. 휴대폰 앱도 같은 규칙이라 API 키 없이도 단순한 등록은 돼요.
- **지난 일정**: 흐리게 보이는 건 완료한 일정뿐이에요. 목록 맨 위에는 지난 30일 동안 아직 완료 안 한 일정이 "지남 · 안 끝냄"으로 남아 있어요 (반복 일정의 지난 회차는 빼고).
- **끌어서 옮기기** (PC):
  - 일정을 다른 날짜 칸에 놓으면 그날로 옮겨요. 시간·길이는 그대로, 반복 일정은 그 회차만. 주간 시간 칸에선 들어갈 자리가 점선으로 보여요.
  - 일정을 왼쪽 할 일 칸에 놓으면 날짜 없는 할 일이 돼요 (장소·메모는 할 일 메모로). 반복 일정은 안 돼요.
  - 할 일을 날짜 칸에 놓으면 그날 종일 일정이 돼요. 주간의 시간 칸에 놓으면 그 시각 일정(1시간)이에요.
  - 끄는 중에 ◀ ▶ 위에 잠깐 있으면 이전·다음 주(달)로 넘어가요. Esc = 취소, Ctrl+Z = 되돌리기.
- **보기**: 목록 / 주 / 월 (Ctrl+1·2·3). 주·월 보기에선 창이 커지고, 빈 칸을 누르면 그 시간에 새 일정.
- **일정 누르기**: 상세 창에서 제목·시간·장소·메모·반복·알림 직접 수정. 반복 일정은 "이 일정만 / 반복 전체" 선택.
- **완료 체크**: 일정 옆 네모칸을 누르면 취소선 + 흐리게 (목록·주·월·상세 창). 반복 일정은 회차마다 따로 체크되고, 완료한 일정은 알림이 안 와요. 구글 일정은 구글에 같이 저장돼서 다른 PC에서도 보여요.
- **기약 없는 할 일**: 창 왼쪽 칸(☑ 버튼·Ctrl+B로 켜고 끄기), 맨 아래 칸에 적고 Enter. ☐ 체크 = 완료, 줄 누르기 = 수정 화면(이름·메모·[삭제], 닫으면 저장), 오른쪽 클릭 → 수정하기·삭제하기, × = 삭제.
- **일정 지우기**: 목록에서 마우스를 올리면 나오는 ×, 또는 일정 오른쪽 클릭 → 수정하기·삭제하기 (목록·주·월 어디서나). 반복 일정은 상세 창에서 "이 일정만 / 반복 전체"를 물어요.
- **지우기 전 확인**: 일정·할 일을 지울 땐 늘 "삭제할까요?"를 한 번 물어봐요.
  - 구글 연결 시 **구글 할 일(Tasks)** 기본 목록에 저장 → 휴대폰 앱·구글 캘린더 앱의 할 일과 같이 보여요. 메모는 구글 할 일 메모.
  - 구글 클라우드에서 **Google Tasks API**도 켜 둬야 해요. 예전에 캘린더만 연결했다면 [구글 다시 연결]로 할 일 권한을 한 번 더 받아요.
- **상태 줄**: 결과 안내는 2초(오류·주의는 6초) 뒤 사라져요. 되돌리기 버튼은 없고 Ctrl+Z나 ⋯ → 되돌리기로 해요.
- **되돌리기**: 등록·수정·삭제·완료 체크·할 일 후 Ctrl+Z 또는 ⋯ → 되돌리기 (최근 30번).
- **알림**: 시간 있는 일정은 시작 10분 전(설정에서 변경)에 윈도우 알림. 일정마다 따로 바꿀 수 있어요.
- **접기**: `–` 버튼이나 Esc를 누르면 화면 오른쪽 아래의 작은 ✱ 버튼으로 줄어들어요. 버튼을 누르면 그 자리에서 창이 위로 펼쳐져요.
  - 버튼에는 오늘 다음 일정 시각이 보이고(1시간 안이면 주황 테두리), 알림이 오면 주황색으로 깜빡여요.
  - 버튼은 끌어서 다른 자리로 옮길 수 있고, 옮긴 자리를 기억해요.
  - 윈도우를 켤 때는 버튼으로만 떠요. 이미 켜져 있을 때 `claude_cal.pyw`를 또 실행하면 창이 펼쳐져요.
  - 작업 표시줄과 Alt+Tab에는 안 나와요 (✱ 버튼과 단축키로 열고 닫아요).
  - 시작 프로그램에 안 넣었거나 `⋯ → 끄기`로 껐다면, 이 폴더의 `claude_cal.pyw`를 더블클릭하면 켜져요.
- **단축키**: 버튼↔창 Ctrl+Shift+Space · 접기 Esc · 새 일정 Ctrl+N · 이전 입력 ↑ · 주·월 이동 ← → · 오늘 T
- 창 위쪽 "✱ 일정" 글자를 잡고 끌어 옮길 수 있어요. 끄기는 `⋯ → 끄기`.
- 메모리는 약 240MB (파이썬 70MB + 화면 엔진 WebView2 170MB).

## 휴대폰 앱 (https://yamchaewoo.github.io/claudecal/app/)

서버 없이 휴대폰 브라우저가 구글·Claude에 직접 연결하는 웹앱이에요. 같은 구글 캘린더를 써서 PC 위젯과 바로 맞춰져요 (완료 체크 포함).

1. 휴대폰 Chrome(아이폰은 Safari)으로 위 주소 열기 → **구글로 로그인** → **API 키** 넣기
2. **홈 화면에 추가** (안드로이드: 앱 안의 버튼 또는 Chrome ⋮ → 홈 화면에 추가 / 아이폰: 공유 → 홈 화면에 추가)
3. 쓰기: 아래 칸에 적고 ➤ · 📋는 복사한 글 붙여넣고 바로 등록
   - 안드로이드: 카톡 메시지 꾹 → **공유 → ClaudeCal** 하면 바로 등록돼요.
- 구글 로그인은 1시간마다 조용히 다시 받아 와요 (화면이 잠깐 넘어갔다 돌아옴).
- 파일은 `site/app/` — `prompt.js`는 `python make_app_prompt.py`로 calcore.py의 지시문에서 만들어요. 고친 뒤 `site`에서 커밋·푸시하면 1분 뒤 반영.
- 시험: `site`에서 `python -m http.server` → `/app/?demo=1` (가짜 구글·가짜 Claude), `?demo=g` (가짜 구글 + 진짜 Claude).
- 구글 클라우드에는 **웹 애플리케이션** 클라이언트가 따로 있어요 (자바스크립트 원본 `https://yamchaewoo.github.io`, 리디렉션 `https://yamchaewoo.github.io/claudecal/app/`).

## Claude 연결 (둘 중 하나)

**API 키 (추천 — 빠름)**
1. https://console.anthropic.com 로그인 → **API Keys → Create Key** → 키 복사 (`sk-ant-…`)
2. 위젯 `⋯ → 설정 → Anthropic API 키`에 붙여넣고 [저장] (저장할 때 키가 맞는지 바로 확인해요)
3. 받은 무료 크레딧은 콘솔의 **Billing**에서 남은 금액을 볼 수 있어요.

| 모델 | 속도 | 1회 대략 비용 | $100이면 대략 |
| --- | --- | --- | --- |
| Haiku | 가장 빠름 | $0.001 | 10만 번 이상 |
| Sonnet (기본) | 보통 | $0.01 | 9천 번 |
| Opus | 가장 똑똑함 | $0.02 | 4천 번 |

⚡ 빠른 등록으로 처리된 입력은 Claude를 안 써서 0원이에요. 비용은 일정 개수에 따라 조금씩 달라지는 대략치예요.

**Claude Code (구독이 있으면)**: Claude Code를 설치하고 터미널에서 `claude` → `/login`으로 본인 계정 로그인. 구독 사용량에서 차감돼요.

> 다른 사람의 API 키나 Claude 계정을 빌려 쓰면 안 돼요. 친구에게 줄 때는 각자 본인 키를 넣게 하세요.
> API 키는 `%APPDATA%\ClaudeCal\config.json`에만 저장돼요. 이 파일은 남에게 보내지 마세요.

## 저장 위치

- **처음엔 이 PC에 저장** (`%APPDATA%\ClaudeCal\events.json`) — 구글 설정 없이 바로 쓸 수 있어요.
- **구글 캘린더 연결**하면 구글에 저장돼서 휴대폰 캘린더에도 보여요. 연결할 때 PC에 있던 일정을 구글로 옮길 수 있어요 (PC 쪽은 백업 파일로 남김).

### A. 구글 클라우드 설정 (배포하는 사람만, 처음 한 번)

친구들은 이 단계 필요 없어요. 만든 `credentials.json`을 같이 주면 됩니다.

1. https://console.cloud.google.com 접속 → 새 프로젝트 만들기 (이름 예: ClaudeCal)
2. **API 및 서비스 → 라이브러리**에서 **Google Calendar API** 검색 → 사용
3. **Google 인증 플랫폼(OAuth 동의 화면)** 시작하기 — 앱 이름 ClaudeCal, 지원 이메일, 대상은 **외부(External)**
4. **데이터 액세스(범위)**에서 `.../auth/calendar.events` 추가
5. **브랜딩**에 홈페이지·개인정보처리방침 주소와 승인된 도메인 넣기 (앱 게시에 꼭 필요해요)
   - `site/` 폴더가 그 두 페이지예요. 깃허브 저장소에 올리고 **Settings → Pages**에서 main 브랜치를 켜면 `https://아이디.github.io/저장소/`로 열려요.
   - 지금 쓰는 주소: https://yamchaewoo.github.io/claudecal/ · https://yamchaewoo.github.io/claudecal/privacy.html (승인된 도메인 `yamchaewoo.github.io`)
6. **대상(Audience)**에서 **앱 게시(Publish app)** → 프로덕션으로 전환
   - ⚠️ "테스트" 상태로 두면 7일마다 다시 로그인해야 해요.
   - 구글 심사는 안 받아도 돼요. 대신 로그인할 때 "확인되지 않은 앱" 경고가 뜨고, 최대 100명까지 쓸 수 있어요.
   - 앱 로고는 올리지 마세요. 올리면 구글 심사를 받아야 해요.
7. **클라이언트 → 클라이언트 만들기** → 유형 **데스크톱 앱** → 만들기 → **JSON 다운로드**
   - 받은 `client_secret_….json`을 다운로드 폴더나 이 폴더에 두면 앱이 알아서 찾아 `credentials.json`으로 가져와요. 이름 바꾸기 필요 없어요.
8. 위젯 `⋯ → 설정 → 구글 캘린더 연결` → 브라우저에서 로그인 ("확인되지 않은 앱" → 고급 → ClaudeCal(으)로 이동 → 허용)

> 설정 화면에서 [구글 캘린더 연결]을 눌렀는데 열쇠 파일이 없으면, 위 단계를 누르면 바로 열리는 링크로 보여 줘요.

> `credentials.json`은 친구들에게만 개인적으로 공유하고, 공개된 곳에 올리지 마세요.

## 설치 (쓰는 사람 모두)

1. **Python 설치**: https://python.org → 설치 첫 화면에서 **"Add python.exe to PATH" 체크**
2. 이 폴더의 **`install.bat` 더블클릭** → 패키지 설치, 시작 프로그램 등록, 실행까지 해 줘요.
3. 위젯 `⋯ → 설정`에서 API 키 넣기.

## 자동 업데이트

- 위젯이 켜고 20초 뒤, 그다음 6시간마다 깃허브 페이지의 `widget/version.json`(1KB)을 확인해요. 새 버전이면 **바뀐 파일만** 받아서(sha256 확인) 바꿔 두고, 창을 버튼으로 접어 둘 때 조용히 다시 켜져요. 부품 목록(requirements.txt)이 바뀌면 설치부터 해요.
- 받은 파일이 이상하거나 인터넷이 안 되면 아무것도 안 바꾸고 다음에 다시 해요. 바꾸기 전 파일은 `%APPDATA%\ClaudeCal\update_backup\`에 남아요.
- `⋯ → 설정 → 업데이트`: 끄기, [지금 확인], [지금 다시 켜기].
- 개발 폴더(옆에 `site` 폴더가 있는 곳)는 업데이트하지 않아요.
- **새 버전 올리기** (개발 폴더에서): `python make_release.py "바뀐 점 한 줄"` → `site/widget/`과 배포 zip을 새로 만들어요 → `site`에서 커밋·푸시. `credentials.json`은 깃허브에 올라가지 않아요.

## 문제 해결

- **"Claude Code에 로그인되어 있지 않아요"**: 설정에서 API 키를 넣거나, 터미널에서 `claude` → `/login`.
- **"API 키가 맞지 않아요" / "크레딧이 부족해요"**: 콘솔에서 키와 Billing을 확인.
- **"단축키 등록 실패"**: 다른 앱이 같은 키를 사용 중. 설정에서 단축키를 바꾸고 껐다 켜기.
- **위젯이 안 보임**: 단축키를 누르거나, `install.bat`/`claude_cal.pyw`를 다시 실행하면 떠 있는 창이 앞으로 나와요.
- **실행 오류**: `%TEMP%\ClaudeCal_오류.txt`에 내용이 남아요.
- **완전히 지우기**: 시작프로그램 폴더(`Win+R` → `shell:startup`)의 `ClaudeCal` 바로가기 삭제, `%APPDATA%\ClaudeCal` 폴더 삭제(일정·설정·키가 들어 있음), 알림 등록 `HKCU\Software\Classes\AppUserModelId\ClaudeCal` 삭제.
